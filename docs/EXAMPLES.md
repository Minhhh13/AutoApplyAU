# Example prompts

Use `$auto-au-applications` in Codex or `/auto-au-applications` in Claude Code. Replace the example details with your own; they are not eligibility assumptions.

## Build a reusable profile

```text
Use $auto-au-applications. Read the CV and transcript I provide and build my profile.
Save it in ./application-data. Keep my original CV intact and ask me about
anything missing or contradictory before using it in an application.
```

## Find a first shortlist

```text
Find 10 Australian internship, vacationer or graduate programs matching my profile.
I prefer Sydney and Melbourne. Search the main boards, then expand to relevant
specialist/startup, government and university sources from the skill's source guide.
Check employer requirements and current deadlines, and deduplicate across boards.
Show eligibility, missing facts and sources for each result. Do not submit anything.
```

You can also give one instruction covering a search and a specific batch:

```text
Find software internships in Melbourne on Prosple, SEEK, Indeed and LinkedIn.
Apply to up to three that match my confirmed profile and have open applications.
Track the result of each one in my Google Sheet.
```

## Expand a narrow search

```text
My shortlist is too small. Broaden the search to additional sources relevant
to my discipline and locations, including Hatch/Wellfound for suitable startup
roles, relevant public-sector portals and my university's careers board.
Keep my eligibility and exclusions unchanged. Report which sources you could
inspect and which only provided unverified leads.
```

## Work from links you found yourself

```text
Create a Google Sheet for my applications. Apply to this specific role using
my saved profile, then track the outcome there: <job listing URL>
```

To check and prepare several roles without sending them:

```text
Check these employer URLs against my saved profile. Deduplicate them against
my tracker, explain any eligibility issues, and prepare the suitable applications.
```

## Prepare answers

```text
Draft this application's motivation and competency responses using my verified
experience examples. Respect the exact word limits and show any missing evidence.
Save the answers with this application rather than changing my master CV.
```

## Fill a batch

```text
Prepare and fill the next three eligible roles from my selected shortlist.
Leave each at final review. Ask for genuinely missing facts together where possible.
```

## Submit a reviewed batch

```text
Submit the two applications I just reviewed. Use the saved final documents
and confirmed choices. Verify receipt and record the real result for each.
```

## Resume after a disconnect

```text
Resume my application-data tracker. The previous session disconnected while
submitting one role. Reconcile any pending or uncertain outcome before retrying,
then continue preparing the other selected roles.
```

## Export progress

```text
Summarise my tracker with deadlines, missing information and next actions.
Export a new CSV for me to review in Excel. Leave the JSON tracker as the source.
```

## Practise assessments

```text
Create original numerical reasoning practice, explain my mistakes and record
the skills I should work on. Use a timed session if the tools support it.
```

An instruction to research or fill is separate from an instruction to submit. Existing authorisation for a specific application or batch remains valid; the skill does not require you to repeat it unless the scope materially changes.

# Changelog

## 0.3.0 — 16 November 2026

- Added an optional Chrome/Edge autofill extension with a local applicant profile and a separate release ZIP.
- Added form guidance for the ten platforms covered by AutoInternshipClaude, plus Oracle Taleo and PageUp.
- Added Chromium checks for supported portal layouts and documented how to start a search on Prosple, SEEK, Indeed and LinkedIn using a role and location.

## 0.2.0 — 16 November 2026

- “Apply to this link” now takes a specific role through eligibility checks, preparation, form filling and confirmed submission when the host supports it. “Fill for review” still stops before submission.
- Link a Google Sheet to an applicant workspace and sync one row per application through your host's authenticated integration. Saved changes survive connection failures and retain an application ID across updates.
- Keep private applicant details, portal links and receipts in the local application files. Share a verified public job listing URL when available.

## 0.1.1 — 16 November 2026

- Expanded discovery to additional general, specialist, startup, university and government opportunity sources.
- Added source selection by discipline, location and existing university/member access, with duplicate and access-gap handling.
- Updated the public examples and documentation for the broader source coverage.
- Removed the "Built for Australia" badge from the repository banner.

## 0.1.0 — 16 November 2026

Initial public release of AutoApply AU.

- Portable Codex and Claude Code skill for Australian internships, vacationer and graduate programs.
- Discovery guidance for Prosple, Indeed Australia, GradConnection/SEEK, LinkedIn and employer sites.
- Evidence-based eligibility checks and tailored document/answer workflow.
- Local application tracker with duplicate detection and uncertain-submission recovery.
- Mechanical answer/evidence checks, blank profile and packet templates.
- Installer, skill ZIP packaging, public setup examples and automated checks.

Live employer portals have not yet been validated end to end. Browser-assisted actions depend on the tools available in the user's host.
